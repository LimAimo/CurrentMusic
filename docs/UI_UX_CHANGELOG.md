## 本地验证

从项目根目录运行：

```bash
cd web
npm install
npm test
npm run build
npm run preview
```

预览站点为 `http://127.0.0.1:4173/`，也可通过 `PORT=8080 npm run preview` 修改端口。这里不是 HMR 开发服务器，每次修改源码后需重新 `npm run build` 并刷新页面。`npm run preview` 需要先构建资源。

## 仍需连接到你的服务端/设备检查

- 用真实服务端账号回归评论新旧排序、编辑歌单排序、点赞状态与高级音频查询；特别是网络抖动和旧服务端回退场景。
- 用 Android WebView、Chrome 移动端、平板与折叠屏检查安全区域、滚动恢复、长按阈值和屏幕阅读器读序。
- `npm test` 是不依赖后端的源码回归检查，不代表已经完成服务端联调与真实设备测试。
- 未对私有后端、数据库、签名、播放链路或受版权限制的音源作任何修改。
